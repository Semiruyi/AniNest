# Anime4K Shader Assets

This directory contains a bundled subset of Anime4K GLSL shader files used by
AniNest's optional desktop video enhancement modes.

Upstream project:

- Anime4K
- https://github.com/bloc97/Anime4K

License:

- MIT

Bundled files in this directory were copied from the upstream Anime4K project
and are used to build the current AniNest presets:

- `Anime4K Off`
- `Anime4K Fast`
- `Anime4K HQ`

AniNest currently ships only the shader files referenced by the player runtime.
If presets change in the future, keep this directory and
`THIRD_PARTY_NOTICES.md` in sync.
